# Kangla 3D map

`/explore/kangla` is a 3D map of Kangla and the streets immediately around it, built on MapTiler vector tiles through MapLibre GL. Google is not involved in it: no Maps JavaScript SDK, no photorealistic tiles, no Google request of any kind. The only remaining Google link on the site is an "open in Google Maps" href on other pages, which goes out to the consumer web map.

The camera is clamped to `KANGLA_MAP_BOUNDS` (`src/lib/immersive/kangla-places.ts`), roughly 1.4 x 1.6 km around the moated enclosure. A visitor can pan, rotate, tilt and zoom inside that box and cannot leave it. This is a map of one place rather than a world map that opens over Manipur.

## Setup

The page reads `MAP_TILER_API_KEY` from `.env.local` and passes it to the client, which is how a MapTiler browser key is meant to be used — the protection is the key's origin allowlist, not secrecy. The key currently in `.env.local` is restricted to `http://localhost:3000`, so:

- Run the dev server on port **3000**. On any other port MapTiler answers 403 and the map shows an authorisation message rather than imagery.
- Before deploying, add the production origin to the key's allowed origins in the MapTiler console.
- `/explore/kangla` is prerendered, so the key is read at build time. A key change needs a rebuild, not just a restart.

Nothing else is required: no billing setup, no per-API enablement.

## What is actually 3D

MapTiler's planet tiles only carry buildings that already have a height tag, which over Kangla is ten features in total — a flat map wearing a 3D label. So the style's own `Building 3D` layer is switched off and the extrusions come from `public/models/kangla/kangla-buildings.geojson`, generated by `scripts/fetch-kangla-buildings.py`: every OpenStreetMap building footprint inside the map bounds, 49 of them, each carrying where its height came from.

| heightSource | count | meaning |
| --- | --- | --- |
| `osm:height` | 0 | a height tagged in metres |
| `osm:levels` | 14 | `building:levels` x 3.2 m |
| `assumed` | 35 | no height in OSM at all, drawn flat at 6 m |

Footprints are OSM geometry as mapped; only the third class is an assumption. Those buildings are shaded a paler stone than the rest and the page carries a legend saying so, so the map never claims to know a roof it does not know. Re-running the script rewrites both the GeoJSON and `src/lib/immersive/kangla-buildings.generated.ts`, which is where the caption's counts come from — they are generated rather than typed in, so they cannot drift from the data.

Terrain comes from MapTiler `terrain-rgb-v2` at exaggeration 1. Imphal sits on a flat valley floor, so this is a true ground surface and a subtle one; exaggerating it would misrepresent the site. If the terrain source fails the map drops it and carries on, because the buildings are the point. Moats and the fort outline are drawn from `kangla-site.geojson`, the repo's existing OSM extract.

The white slab inside the southern enclosure is MapTiler's aviation fill over the helipad mapped there. It is real data, not a rendering fault.

## Checks

`npm run typecheck`, scoped ESLint and `npm run build` all pass. `scripts/check-kangla.mjs` drives a real browser against **port 3000** and asserts: MapTiler provider and no error alert, MapTiler's extrusion layer off and ours on, more than ten extruded buildings actually rendered, terrain attached, moat and boundary layers non-empty (an empty one means the MapLibre worker silently failed), the camera clamped inside the bounds, the 2D/3D and label toggles, recenter, MapTiler and OpenStreetMap attribution visible, mobile sizing without overflow, no Google request and no GLB/HDR download, and the alert-plus-retry path when the style will not load. It accepts `PLAYWRIGHT_MODULE`, `BROWSER_EXECUTABLE` and `TEST_BASE_URL`.

Last run: pass, with 32 buildings drawn in the opening view.

## Not covered

The landmark studio at `/immersive/kangla-fort` redirects to this map; its Three.js components are still in the tree but unreachable. The map does not load those GLBs and does not mix modelled reconstructions into MapTiler's data.
